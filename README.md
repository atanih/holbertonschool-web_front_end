# Techium - HTML Advanced

This project focuses on structuring a web page using HTML5 semantic tags for the company **Techium**. No CSS or styling is used — the goal is to learn proper HTML structure.

## Learning Objectives

- Create the skeleton of an HTML5 page
- Use semantic HTML tags to structure a web page
- Understand when to use `div` vs `span`
- Apply proper heading hierarchy
- Build lists, tables, and integrate media (images, video, audio)
- Embed external content

## Requirements

- W3C compliant HTML5
- Semantic tags for page structure
