# CSS Advanced

Maquetación de la página de inicio de **Techium** aplicando CSS avanzado
sobre una estructura HTML semántica ya existente.

## Objetivos

- Selectores, propiedades y valores
- Diferencia entre estilos de bloque y en línea
- Consistencia entre navegadores con un CSS reset
- Variables CSS
- Diferencias entre CSS inline, embebido y externo
- Sistemas de rejilla con floats
- Diferencia entre iconos webfont e iconos SVG
- Diferencia entre pseudo-clases y pseudo-elementos
- Degradados de fondo
- Animaciones y transformaciones 2D y 3D
- Prefijos de proveedor

## Requisitos

- Los archivos se interpretan en Chrome (versión 78.x)
- Todos los archivos terminan con un salto de línea
- Todos los archivos empiezan con un comentario que describe la tarea
- El código valida con el W3C Validator

## Estructura

```
CSS_advanced/
├── index.html      # estructura de la página
├── images/         # 13 imágenes: 10 de contenido, 2 logos y el favicon
└── styles/         # una hoja de estilos por tarea
```
